# Joshua S. Mobile Detailing

Responsive static website built with plain HTML, CSS, and JavaScript.

## Files
- index.html: page content and accessible estimate dialog
- styles.css: charcoal and gold design and responsive layouts
- script.js: vehicle prices, add-ons, first-detail estimate, SMS inquiry, and mobile menu
- assets/hero.png: original AI-generated automotive illustration
- assets/car-logo-gold.png: gold car logo in header and footer
- assets/favicon.svg and assets/favicon-32.png: gold car browser icons
- assets/apple-touch-icon.png: home-screen icon

Open index.html in a browser, or serve the folder with any static web server. Upload this folder to any static website host. Google Fonts requires internet; system fonts are used as a fallback.

Contact: Joshua S., 862-777-0163. North Jersey mobile service. Business facts and prices transcribed from the two supplied images. The site uses Joshua's name as its display identity. Package descriptions organize the flyer’s general service list into interior and exterior care; confirm inclusions with the owner before a public launch. The first-detail offer is estimated on the package, with extras added afterward; its terms need owner confirmation. Booking opens a prepared SMS inquiry; no booking or message is sent automatically, and there is no server or payment collection.
